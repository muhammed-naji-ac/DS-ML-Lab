## ✦ About

**DS-ML-Lab** is a hands-on laboratory for exploring the fundamentals of **Data Science, Data Analysis, Statistics, and Machine Learning**.

It brings together small experiments, Python programs, and real-world datasets in one place.

> **Learn the concept. Write the code. Understand the data.**

---

```text
DS-ML-Lab/
│
├── 🐍 Python Programs
├── 📊 Datasets

├── 📈 Visualization
└── 🤖 Machine Learning
```

### Datasets

* 🌸 **Iris** — classification & exploration
* 🩺 **Diabetes** — data analysis & prediction
* 🎓 **Marks** — statistical analysis
* 📄 **Additional datasets** — programming experiments

## ⚡ Quick Start

```bash
git clone https://github.com/muhammed-naji-ac/DS-ML-Lab.git
cd DS-ML-Lab

pip install numpy pandas matplotlib scipy scikit-learn
```

Run any experiment:

```bash
python prgm1.py
```
