## 🧭 Overview

Welcome to **DS-ML-Lab**—a comprehensive sandbox and digital laboratory dedicated to uncovering patterns in data, building predictive systems, and implementing machine learning algorithms from scratch. 

Whether it's preprocessing messy raw data, visualizing high-dimensional features, or training deep neural networks, this repository serves as a structured collection of implementations, projects, and lab exercises.

## 📌 About

**DS-ML-Lab** is a practical collection of Data Science and Machine Learning laboratory exercises implemented in Python.

The repository brings together programming experiments, data-processing tasks, and dataset-driven exercises in one place — turning theoretical concepts into executable experiments.

Instead of treating Data Science as only mathematics and theory, this lab follows a simple philosophy:

> **Learn the concept → Write the code → Work with data → Observe the result → Improve the solution.**

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/muhammed-naji-ac/DS-ML-Lab.git
cd DS-ML-Lab
```

### 2. Create a virtual environment

```bash
python -m venv .venv
```

Activate it:

**Windows**

```bash
.venv\Scripts\activate
```

**Linux / macOS**

```bash
source .venv/bin/activate
```

### 3. Install dependencies

If a `requirements.txt` file is added to the project, install dependencies with:

```bash
pip install -r requirements.txt
```

For individual programs, install the libraries required by that particular exercise.

### 4. Run a program

```bash
python prgm1.py
```

or:

```bash
python prg11.py
```
